# 노리박스 홈페이지

오락실게임기 브랜드 **노리박스**를 위한 반응형 정적 홈페이지입니다. 빌드 도구 없이 `index.html`을 바로 열어 확인할 수 있습니다.

## 파일

- `index.html` — 사이트 구조와 한국어 임시 콘텐츠
- `about.html` — 창업자 인터뷰를 바탕으로 만든 1인칭 브랜드 이야기
- `products.html` — `products.json`에서 생성되는 전체 제품 목록
- `products.json` — 제품명, 상황 문구, 가격, 이미지 주소, 스마트스토어 구매 링크
- `story/` — `posts.json`으로 운영하는 이야기 목록, 상세 글, 관리자 페이지
- `styles.css` — 화이트·차콜·코발트 3색 디자인 시스템과 반응형 레이아웃
- `script.js` — 제품·최신 이야기 카드 생성, 모바일 메뉴, 스크롤 표시, 문의 폼 데모
- `assets/images/` — 노리박스 공식 사이트에서 가져온 제품 사진과 출처

## 수정이 필요한 임시 항목

- 최종 로고 파일
- 제품의 확정 사양과 가격
- 이메일, 전화번호와 영업시간
- 블로그 게시물 링크와 본문
- 문의 폼 전송 서비스

새 제품은 `products.json`의 `products` 배열에 추가하면 홈 큐레이션과 전체 제품 페이지에 자동 반영됩니다. 홈에는 지정된 대표 제품 1개와 그 외 앞 5개 제품이 표시됩니다.

새 글은 `story/posts.json`에 추가하면 이야기 목록과 홈의 최신 이야기 3개에 자동 반영됩니다.

스크롤 리빌과 카드 호버는 운영체제에서 동작 줄이기를 설정하면 자동으로 비활성화됩니다.

## 로컬 확인

`index.html`을 브라우저에서 직접 열거나 다음 명령으로 로컬 서버를 실행하세요.

```powershell
python -m http.server 4173
```

Vercel 배포에서는 `vercel.json`의 `cleanUrls` 설정으로 `about.html`을 `/about` 주소에서도 제공합니다.

## 구매후기·SEO 회귀 검사

Node.js 22 이상에서 다음 명령으로 확인합니다.

```sh
node --test scripts/tests/*.test.mjs
node scripts/audit-seo.mjs
node scripts/check-footers.mjs
```

테스트는 임시 폴더와 가짜 네이버 응답으로 동기화 과정을 재현하며, 실제 후기를 조회하거나 저장소의 원문 데이터를 변경하지 않습니다. 홈의 고객 제목은 저장된 후기 ID·공식 카페 원문 URL·생성 카드가 모두 일치할 때 제목 텍스트만 금지 표현 검사에서 제외합니다. 카드 주변 브랜드 문구는 계속 검사하며, 실패 시 파일명과 해당 표현 또는 출처 불일치를 출력합니다. 원문 데이터 자체의 진위는 기존 수집 과정과 코드 리뷰에서 확인해야 합니다.
