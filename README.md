# 노리박스 홈페이지

오락실게임기 브랜드 **노리박스**를 위한 반응형 정적 홈페이지입니다. 빌드 도구 없이 `index.html`을 바로 열어 확인할 수 있습니다.

## 파일

- `index.html` — 사이트 구조와 한국어 임시 콘텐츠
- `styles.css` — 반응형 디자인과 애니메이션
- `script.js` — 모바일 메뉴, 스크롤 표시, 문의 폼 데모

## 수정이 필요한 임시 항목

- 실제 로고와 브랜드 색상
- 제품 사진, 이름, 사양과 가격
- 이메일, 전화번호와 영업시간
- 블로그 게시물 링크와 본문
- 문의 폼 전송 서비스

## 로컬 확인

`index.html`을 브라우저에서 직접 열거나 다음 명령으로 로컬 서버를 실행하세요.

```powershell
python -m http.server 4173
```
